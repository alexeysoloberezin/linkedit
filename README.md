# Link Edit

Переносит параметры (gclid, gbraid, gad_* и т.д.) с исходной ссылки на новый домен и добавляет тег `a=` первым параметром.

- **Исходная ссылка** — из неё берутся все параметры после `?` (каждый можно выключить чекбоксом).
- **Тег a** — значение `a=`. Если в исходной ссылке уже есть `a`, оно заменяется введённым.
- **Домен** — куда переносим. `https://` добавляется автоматически.

Статический сайт без сборки (`index.html`), деплой на Vercel.
